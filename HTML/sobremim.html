Galeria Seleta

Detalhes

Galeria Seleta foi um projeto para realização de um trabalho acadêmico em minha faculdade. Tivemos essa ideia de projeto para trazer um brechó real para o mundo da internet, pois eu e meu grupo encontramos em comum a paixão por roupas. Onde sabemos que temos uma escabilidade muito maior conseguindo conquistar uma grande comunidade, que consequentemente aumentando o número de vendas. Para desenvolver esse projeto utilizamos, CSS, HTML, JS e NodeJS. Nosso maior desafio ao desenvolver esse projeto foi a manipulação do Node e JS, pois eram linguagens que não dominávamos 100%.
